# AI 知识博主封面风格规范（完整版）

SKILL.md 里的主提示词已经浓缩了核心规则，这份是逐模块的细则，供调参和排查问题时查阅。

> **参考图优先级最高**：`assets/cover-01.jpg` ~ `cover-04.jpg`（或用户提供的参考图）是版式的权威依据，不是灵感参考。**文字和人像的分布比例、字号大小、页面占比**这几项，直接照抄参考图的实际效果；本文档里的文字描述只是辅助说明，两者有出入时以参考图为准。详见「四、排版」末尾的完整说明。

## 一、整体风格定位

风格关键词：爆款封面 + YouTube Thumbnail + AI 知识博主 + 高点击率 + 干净高级 + 真人 IP

整体感觉：
- 第一眼就知道讲 AI
- 第一眼就看到标题
- 第一眼就看到人物
- 没有复杂设计、没有廉价营销感
- 不像海报，更像百万播放的视频封面

## 二、人物要求（最重要）

人物是真人 IP，要**真人感**，不要过度 AI 脸。

不要：网红磨皮 / 塑料皮肤 / 假睫毛 / 滤镜脸 / 大眼娃娃脸
应该：保留真实肤质 / 自然光影 / 一点皮肤纹理

轻微磨皮即可——去法令纹、额头细纹、痘印、黑眼圈，而不是全部磨掉。

五官比例：脸型瘦一点、下颌线更清晰、下巴不要过尖、保持真人比例。目标是「真人稍微上镜」，不是「AI 美女」。

**人物位置统一：右侧、偏右、偏下，左边留大量空间放标题。**

**左右大致各占一半，不用精确切割**：人物为主的一侧和文字为主的一侧都要撑满各自空间，不能有大片空白；但两者之间可以有自然的重叠——人物的手臂、肩膀、头发压到文字边缘，是允许的，甚至更真实。唯一底线是**人脸不能被文字遮挡**。

**人物尺寸是近景大特写，不是缩小的全身照。** 头部到身体占满画面上下大部分高度，头顶留一点点自然呼吸空间即可（不用死贴边），人物本身要撑满自己一侧的空间，而不是漂在中间四周留白。

**先和用户确认表情情绪基调，再生成**：不要跳过确认步骤直接随机生成表情。基调选项和组合规则见 SKILL.md 的「表情情绪基调库」（自信干练 / 亲切开怀 / 活泼俏皮 / 专注讲解 / 沉稳思考 / 惊讶种草，或用户自定义）。**核心原则是眼神、眉毛、嘴部必须属于同一情绪基调，组合起来要和谐自然，不能互相矛盾**（比如「露齿大笑」不能配「微皱思考」，「睁大惊讶」不能配「抿嘴不动」）。头部角度和手势可以在同一基调内相对自由地搭配，用来在多个版本之间制造差异。**同一张照片生成多个版本时，都保持在用户确认的情绪基调内，只变化头部/手势**，让用户能挑到最满意的一版。

❌ 反面例子：人物站在画面中间偏右，四周留了很多背景空白（像证件照放大后贴在图上），这样即使人物清晰，整张封面的视觉重量也会偏轻、点击率会下降。
❌ 反面例子：多个版本表情、姿势完全一样，只是换了文字——达不到「供挑选」的目的。
❌ 反面例子：眼神/眉毛/嘴部情绪基调矛盾（比如眼睛惊讶睁大却嘴巴抿着不动），看起来不自然。
❌ 反面例子：没有先问用户想要什么情绪基调，直接随机拼凑表情——生成的版本可能都不是用户想要的方向。
❌ 反面例子：只把嘴角改成微笑，眼神和眉毛没变化，看起来像贴图，不自然。

## 三、标题风格（核心）

- **超大**，占据画面左侧大致一半的空间，是 YouTube Thumbnail 风格；不用精确切割，末尾文字延伸到人物身前也可以。
- **拆成 4–5 行短句**：从画面顶部一路排到接近底部，不能只写 2-3 行短标题堆在左上角、下方大片空白。标题字数不够铺满时，用换行、拆分词组、放大字号来填满，而不是留白。
- **字号要有明显的大中小层次**：数字/收尾重点句最大 > 中间短句中等 > 普通连接词最小，形成强烈节奏感。禁止全篇标题用同一个字号（那样会显得单调、没有视觉冲击力）。
- **重点短句用「色块高亮」，不是只改文字颜色**：给关键词/关键短句加一块奶油黄色块或白色圆角色块压在文字底下（像马克笔高亮一样把文字"垫"起来），而不是仅仅把文字改成黄色。参考 `assets/cover-01~04.jpg` 里「转行AI岗位」「有壁垒」「天花板」这类色块压字的效果。一张封面里通常 1–2 句用色块高亮就够，不用每句都加。
- 字体：粗黑体，超粗，有力量。
- 描边：白字黑描边 / 黄字黑描边 / 'AI' 黑描边 / 数字黑描边，描边较厚。
- 颜色只用四种：白色、奶油黄、黑色、橙色（强调数字）。
- 奶油黄要低饱和（#F6D66B 或 #F2D27A），不是亮黄 / 荧光黄。
- 'AI' 一定完整露出，绝不能被头、身体或文字挡住。
- 数字一定放大（如 24 小时 / 4 个 / 10+ / 2 分钟），全部橙色，最大最醒目。

❌ 反面例子：所有文字用同一个字号、只占左上角一小块、下方空着——这样视觉冲击力弱，会被信息流刷过去。
❌ 反面例子：重点词只是把文字颜色换成黄色，没有色块背景——层次感和吸睛度会弱很多。

## 四、排版（最大特点）

左文字 + 右人物，大致各占一半，不用精确切割。**留白只留在文字和人物内部的呼吸空间，不能整体大片留白**——左侧被文字撑满（顶到底），右侧被人物撑满（占满上下大部分高度、头顶留少量自然呼吸空间即可）。

**文字和人物允许自然重叠交互**：人物的手臂、肩膀、头发压到文字边缘，或标题最后一两个字延伸到人物身前，都是可以的，会让画面更有真实感和层次感，不用像拼贴一样切得整整齐齐。唯一硬性要求：**人脸不能被文字挡住，数字/重点词/'AI' 不能被人物挡住**。

推荐布局示例（4–5 行短句、字号大小交替、末尾 1–2 句用色块高亮，允许与人物自然重叠）：

【中黑|无色块】找到真正                    [ 人物特写

【大黄色块】转行                             上下大部分高度
【超大黄色块】AI 岗位 ⟵可与手臂/肩膀自然重叠   ]

```

```

【中黑|无色块】转行

**风格锚定，参考图优先级最高**：生成前把 `assets/cover-01.jpg` ~ `cover-04.jpg`（或用户提供的参考图）当作权威范例，不是灵感参考——**文字和人像的分布比例、字号大小、页面占比**这几项，直接照抄参考图的实际效果，本文档和 SKILL.md 里的文字描述只是辅助说明。如果文字规则和参考图的实际效果有出入（比如文字写「大致各占一半」但参考图里实际是 55/45），以参考图为准。

## 五、背景

真实生活场景：办公室 / 咖啡馆 / 植物 / 电脑 / 书桌 / 窗户 / 自然光。

**背景要和人物自然过渡、融为一体**：光影方向、色温、虚化程度要和人物本身的光线保持一致，不能出现明显的抠图边缘或拼贴感，不能让人一眼看出「人物是贴上去的」。

不要：AI 科技背景 / 蓝色科技感 / 未来城市 / 赛博朋克 / 发光芯片。因为真人 IP 最重要。

## 六、小元素

允许一点点：✨ ✔ 箭头 / 黄色笔刷 / 漫画线。控制在 5 个以内，作用是增加活力，不是装饰。

## 七、整体颜色

暖色、奶油色、木质色、自然光，非常舒服。不能太艳、不能太冷、不能蓝紫色。

## 八、画质

高清、自然、像 iPhone 拍出来。不要 AI 渲染感、HDR 过重、过曝。

## 九、核心公式

左右大致各占一半 ＋ 真人 IP 大特写铺满右侧、表情在确认的情绪基调内和谐变化 ＋ 4-5 行大中小字号层次的标题铺满左侧 ＋ 重点短句色块高亮压字 ＋ 文字与人物自然重叠交互 ＋ 白字黑描边 ＋ 少量漫画元素 ＋ 自然办公背景 ＋ 不过度美颜 ＋ YouTube Thumbnail 排版 ＋ 小红书知识博主风格。左右都不留大片空白，人脸和核心文字不被遮挡。

## 十、优先级约束

优先保证点击率而非设计感：标题可读性第一，人物辨识度第二，装饰元素第三。整张封面在小红书两列流缩略图尺寸下，用户 1 秒内能看清标题，并立即识别人物与主题。
