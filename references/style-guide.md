# AI 知识博主封面风格规范（完整版）

SKILL.md 里的主提示词已经浓缩了核心规则，这份是逐模块的细则，供调参和排查问题时查阅。

## 一、整体风格定位

风格关键词：爆款封面 + YouTube Thumbnail + AI 知识博主 + 高点击率 + 干净高级 + 真人 IP

整体感觉：
- 第一眼就知道讲 AI
- 第一眼就看到标题
- 第一眼就看到人物
- 没有复杂设计、没有廉价营销感
- 不像海报，更像百万播放的视频封面

## 二、人物要求（最重要）

人物是真人 IP，要**真人感**，不要过度 AI 脸。

不要：网红磨皮 / 塑料皮肤 / 假睫毛 / 滤镜脸 / 大眼娃娃脸
应该：保留真实肤质 / 自然光影 / 一点皮肤纹理

轻微磨皮即可——去法令纹、额头细纹、痘印、黑眼圈，而不是全部磨掉。

五官比例：脸型瘦一点、下颌线更清晰、下巴不要过尖、保持真人比例。目标是「真人稍微上镜」，不是「AI 美女」。

**人物位置统一：右侧、偏右、偏下，左边留大量空间放标题。**

**左右严格各占画面宽度的一半**：人物区域占右侧 50%，不能被文字挤占，也不能自己缩小到不足一半。

**人物尺寸是近景大特写，不是缩小的全身照。** 头部到身体占满画面上下大部分高度，头顶留一点点自然呼吸空间即可（不用死贴边），人物本身要撑满右侧空间，而不是漂在中间四周留白。

❌ 反面例子：人物站在画面中间偏右，四周留了很多背景空白（像证件照放大后贴在图上），这样即使人物清晰，整张封面的视觉重量也会偏轻、点击率会下降。

## 三、标题风格（核心）

- **超大**，占据整个左半边（宽度约 50%，不越过画面竖直中线），是 YouTube Thumbnail 风格。
- **拆成 4–5 行短句**：从画面顶部一路排到接近底部，不能只写 2-3 行短标题堆在左上角、下方大片空白。标题字数不够铺满时，用换行、拆分词组、放大字号来填满，而不是留白。
- **字号要有明显的大中小层次**：数字/收尾重点句最大 > 中间短句中等 > 普通连接词最小，形成强烈节奏感。禁止全篇标题用同一个字号（那样会显得单调、没有视觉冲击力）。
- **重点短句用「色块高亮」，不是只改文字颜色**：给关键词/关键短句加一块奶油黄色块或白色圆角色块压在文字底下（像马克笔高亮一样把文字"垫"起来），而不是仅仅把文字改成黄色。参考 `assets/cover-01~04.jpg` 里「转行AI岗位」「有壁垒」「天花板」这类色块压字的效果。一张封面里通常 1–2 句用色块高亮就够，不用每句都加。
- 字体：粗黑体，超粗，有力量。
- 描边：白字黑描边 / 黄字黑描边 / 'AI' 黑描边 / 数字黑描边，描边较厚。
- 颜色只用四种：白色、奶油黄、黑色、橙色（强调数字）。
- 奶油黄要低饱和（#F6D66B 或 #F2D27A），不是亮黄 / 荧光黄。
- 'AI' 一定完整露出，绝不能被头、身体或文字挡住。
- 数字一定放大（如 24 小时 / 4 个 / 10+ / 2 分钟），全部橙色，最大最醒目。

❌ 反面例子：所有文字用同一个字号、只占左上角一小块、下方空着——这样视觉冲击力弱，会被信息流刷过去。
❌ 反面例子：重点词只是把文字颜色换成黄色，没有色块背景——层次感和吸睛度会弱很多。

## 四、排版（最大特点）

左文字 50% + 右人物 50%。不要文字压人物、不要文字盖脸、不要人物挡标题。**留白只留在文字和人物内部的呼吸空间，不能整体大片留白，也不能让文字区域挤占人物空间**——左侧被文字撑满（顶到底，宽度约 50%），右侧被人物撑满（占满上下大部分高度、占宽约 50%，头顶留少量自然呼吸空间即可）。

推荐布局示例（4–5 行短句、字号大小交替、末尾 1–2 句用色块高亮）：

```
【超大橙|无色块】24 【中黑|无色块】小时内，
【中黑|无色块】找到真正
【中黑|无色块】适合你的
【大黄色块】转行
【超大黄色块】AI 岗位
                          [ 人物特写
                            占右侧50%宽度
                            上下大部分高度 ]
——————————————————————————
```

```
【中黑|无色块】文科生
【中黑|无色块】转行
【大黄色块】AI，
【大白色块】这个岗位
【超大橙|白底】有壁垒
                     [ 人物特写
                       占右侧50%宽度
                       上下大部分高度 ]
——————————————————————————
```

反面例子（禁止）：

```
24小时内                    [ 小尺寸全身人像
找到真正适合你的               四周留白很多 ]
转行AI岗位（只变色不加色块）

（下方大片空白，文字区域却超过一半宽度）
——————————————————————————
```

**风格锚定**：生成前把 `assets/cover-01.jpg` ~ `cover-04.jpg` 当作真实范例参考——版式、字号节奏、色块高亮方式都以这 4 张图为准，文字描述只是辅助说明。

## 五、背景

真实生活场景：办公室 / 咖啡馆 / 植物 / 电脑 / 书桌 / 窗户 / 自然光。

**背景要和人物自然过渡、融为一体**：光影方向、色温、虚化程度要和人物本身的光线保持一致，不能出现明显的抠图边缘或拼贴感，不能让人一眼看出「人物是贴上去的」。

不要：AI 科技背景 / 蓝色科技感 / 未来城市 / 赛博朋克 / 发光芯片。因为真人 IP 最重要。

## 六、小元素

允许一点点：✨ ✔ 箭头 / 黄色笔刷 / 漫画线。控制在 5 个以内，作用是增加活力，不是装饰。

## 七、整体颜色

暖色、奶油色、木质色、自然光，非常舒服。不能太艳、不能太冷、不能蓝紫色。

## 八、画质

高清、自然、像 iPhone 拍出来。不要 AI 渲染感、HDR 过重、过曝。

## 九、核心公式

左右各占 50% ＋ 真人 IP 大特写铺满右侧 ＋ 4-5 行大中小字号层次的标题铺满左侧 ＋ 重点短句色块高亮压字 ＋ 白字黑描边 ＋ 少量漫画元素 ＋ 自然办公背景 ＋ 不过度美颜 ＋ YouTube Thumbnail 排版 ＋ 小红书知识博主风格。左右都不留大片空白。

## 十、优先级约束

优先保证点击率而非设计感：标题可读性第一，人物辨识度第二，装饰元素第三。整张封面在小红书两列流缩略图尺寸下，用户 1 秒内能看清标题，并立即识别人物与主题。
